# homebrew-tap

Homebrew tap for tools by [jmcampanini](https://github.com/jmcampanini). GoReleaser updates the casks in `Casks/` on each release; do not edit them by hand.

```sh
brew install jmcampanini/tap/overlay
```

| Cask | Source |
|---|---|
| `overlay` | <https://github.com/jmcampanini/overlay> |
